## 推荐阅读路径

1. 阅读根目录 [README](../README.md) 了解整体系统与最终数字；
2. 阅读 [项目故事](PROJECT_STORY_CN.md) 理解问题拆分逻辑；
3. 查看 `experiments/learned_stability_map_20260911/` 了解最新地图学习实验；
4. 查看 `tests/` 了解关键机制如何被回归测试保护；
5. 根据兴趣进入 `semantic_stability_20260731/` 或 `target_motion_*` 查阅完整实验脚本。

## 为什么保留实验分支

机器人定位中很多有效结论来自“什么方法在什么条件下没有改善”。因此仓库保留了对照实验和早期方案，但在 README 中只将通过固定划分验证、能够清楚说明适用范围的版本作为主线结果。这样既能展示迭代过程，也避免把探索性分支误写成最终能力。
