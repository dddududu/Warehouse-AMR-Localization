# 在线多假设精定位

本轮直接处理已确认的主要误差来源：Top-5 已含可用地图块，但单一 tracker 在某一帧将第一名写成唯一状态后，后续帧只能沿错误状态继续细化。实现保留多个独立的候选轨迹；每条轨迹分别使用自己的运动预测、tracker 初始化、深度候选匹配与 ICP 结果。每帧按累计联合分数扩展，随后按空间距离去除重复状态，保留有限条相互分离的轨迹。

`beam1` 是与新框架完全相同的单状态对照；`beam3` 保留三条状态并从每条状态扩展三条候选。二者共享粗定位、深度模型、ICP 参数和测试序列，差异仅为是否允许保留替代定位假设。该实验不使用 Oct.12 真值选择轨迹，真值仅用于最终误差统计。

第二版在某条状态的全部候选暂时违反运动门控时，不再只把 tracker 预测留作唯一解，而是并行保留 tracker 安全支路与由深度候选重启的重捕获支路。两条支路以相同的当前候选质量为起点，后续由连续帧的深度匹配、局部几何和运动一致性自然淘汰。这使短时遮挡或一次错误细化不会永久阻断重新定位。

## 初步结果

在 Oct.12 Aisle_CCW 的前 100 帧中，`beam1` 与 `beam3` 使用同一新在线框架，因此可直接比较。`beam3` 的平均位置误差为 `0.2347 m`，低于 `beam1` 的 `0.2526 m`；P95 由 `0.8376 m` 降至 `0.7036 m`，最大误差由 `1.6724 m` 降至 `1.3475 m`，低于 1 m 的比例由 `96%` 提升到 `97%`。改善集中在 frame 93-99 的连续偏移段，说明保留替代轨迹能减缓单一状态发生偏移后的累积误差。

该结果不能与既有的完整 Aisle 最优系统直接比较：这里为了隔离多假设机制，使用的是相同的候选级安全门控框架，而不是既有的全套在线规则。第一版已确认具备候选选择恢复能力，下一步应学习更可靠的状态质量而非继续放宽重捕获条件。

## 未推广分支

启用 `multi_hypothesis_keep_reacquisition_branch` 的实验版本允许深度候选在全部运动门控失败时直接重启。实测前 100 帧平均误差升至 `1.5004 m`，低于 0.5 m 的比例降为 `84%`，原因是重复货架能产生高置信但错误的深度重捕获。因此该开关默认关闭，只作为后续训练状态质量模型时的困难负样本来源。
