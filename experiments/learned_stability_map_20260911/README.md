# 学习型语义稳定地图（2026-09-11）

本实验把原先由人工公式计算的语义稳定性，改为由局部地图证据预测“该栅格在另一天是否仍适合作为定位依据”。训练输入只来自 Jun15 初始地图：邻域内的观测次数、静态/半动态/动态语义占比、人工稳定性基线和语义熵；监督目标只来自 Jun23 新增观测中的语义可靠性、观测支撑度与跨日一致性。Oct12 Aisle 数据不参与数据构建、训练、早停或权重选择，只在最终候选重排序阶段盲测。

为避免相邻栅格同时落入训练与验证导致的空间泄漏，样本按地图坐标块划分，验证块与训练块空间分离。网络是轻量卷积网络：它读取一个 `9×9` 的局部语义地图窗口，经三层卷积聚合邻域结构，再输出中心栅格的 `[0,1]` 可靠性预测。它不是直接把语义图当作定位器，而是为原有候选匹配提供低权重的稳定性调制；这保留了描述子、分类器和几何精配准在重复货架场景中的主导作用。

运行顺序：先执行 `build_learning_dataset.py --config train.yaml`，再执行 `train_stability_map_net.py --config train.yaml`，最后执行 `evaluate_learned_map_rerank.py --config rerank.yaml`。生成的 `learned_stability_map.npz` 仅含 Jun15 初始地图与模型推理结果，可安全用于后续 Oct12 盲测；盲测报告同时对比同一初始地图上的人工稳定性和学习稳定性。

首轮运行结果及其局限见 `RESULTS.md`。训练在本机 Windows 环境若触发多个 OpenMP 运行库冲突，可设置 `KMP_DUPLICATE_LIB_OK=TRUE` 后运行；这是本机依赖兼容设置，不改变训练数据或模型计算。
